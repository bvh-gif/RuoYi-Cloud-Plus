## 1. 项目目标



以现有 RuoYi-Cloud-Plus 项目为实践对象，逐步建立可重复、可观测、可恢复的本地开发与部署流水线，为后续个人 DevOps 平台及 Agent Runtime 基础设施积累工程经验。
